# Rhythm Workshop

A sort-to-the-beat learning game for children aged 3–6: toys ride a conveyor belt, the child drags each into the right bin, and every correct sort adds a chime that lands on the beat. Free, offline, no ads, no tracking, no backend. Publisher: HomiLabs Solutions.

## Source of truth
- `docs/design-document-v0.md`: the owner's reviewed design.
- `docs/design-review-v1.md`: locked decisions (§0) and build-time choices (§1). It wins where the two conflict.

## Locked
- Flutter (SDK at `/mnt/storage/projects/flutter/bin`), Android only, landscape only.
- Package `com.homilabs.rhythmworkshop`: never change it after the first Play upload.
- No INTERNET permission in release, and no analytics, crash-reporting, ad or Firebase packages.
- Non-punitive rules: a correct drop always counts (auto-quantise); wrong drops float back; toys are never lost.
- Level BPM must equal its music's BPM, because the beat is read from the music position.
- **Don't use Gemini** (no API calls). If richer assets are wanted, give the owner manual steps (`docs/gemini-asset-requests.md`); they upload the results.

## Code map
- `lib/game/`: `workshop_game.dart` (Flame game: beats, spawning, drops), `rules.dart` (pure rules: queue, judging, streak, speed, pattern; `findTarget`), `layout.dart` (all positions in dp), `toy.dart` (one-finger drag, 24 dp grab margin), `bin.dart`, `pattern_shelf.dart`, `belt.dart`, `characters.dart` (Milo, Pip), `effects.dart`.
- `lib/audio/`: `audio_engine.dart` (flutter_soloud; `SilentAudioEngine` for tests), `beat_clock.dart`.
- `lib/levels/level.dart` reads `assets/levels/*.json` (generated by `scripts/make_levels.py`).
- `lib/screens/`: splash, home, world/level pickers, gameplay (hold-to-pause), reward (song replay + xylophone), goodnight, parent settings.
- `lib/settings/game_settings.dart`: the single `ChangeNotifier` (shared_preferences). `lib/widgets/parental_gate.dart`.

## Commands
- Host tests: `flutter test` (93 tests: rules, beat clock, layouts, assets, full level play with real drags, screens).
- Device test: build first, then run with the emulator up:
  `flutter build apk --debug -t integration_test/app_test.dart` then
  `flutter drive --driver=test_driver/integration_test.dart --target=integration_test/app_test.dart --use-application-binary build/app/outputs/flutter-apk/app-debug.apk -d emulator-5590`
- Release: `flutter build appbundle --release` (signs via `android/key.properties` → `.secrets/rhythm-workshop-upload.keystore`).
- Assets (venv `~/tools/venvs/rhythm`): `scripts/make_audio.py`, `scripts/make_voice.py` (Kokoro model in `~/tools/kokoro/`), `scripts/import_voice.py`, `scripts/make_art.py` (Inkscape), `scripts/make_icons.py`, `scripts/make_store_assets.py`, `scripts/make_levels.py`.
